# Obesity Risk Analytics Pipeline

## Overview

This project explores obesity-related data using statistical analysis, data visualization, and machine learning techniques in R. It analyzes factors associated with obesity and builds classification models to predict obesity status and obesity categories.

## Objectives

- Explore and clean the dataset.
- Perform exploratory data analysis and visualization.
- Apply statistical methods to examine relationships between variables.
- Build and evaluate machine learning classification models.
- Compare binary and multiclass prediction approaches.
- Apply Principal Component Analysis (PCA) and Naive Bayes analysis.

## Models and Methods

- Binary Logistic Regression
- Multinomial Logistic Regression
- Ridge Regression
- LASSO Regression
- Decision Tree
- Random Forest
- Naive Bayes
- Principal Component Analysis (PCA)

## Technologies Used

- R
- Jupyter Notebook
- Statistical analysis
- Data visualization
- Machine learning

## Project Structure

- `Obesity_Risk_Analytics_Pipeline.ipynb` — main notebook containing the analysis and modelling workflow.
- `scripts/` — R scripts used in the project.
- `data/` — dataset files required to run the analysis.

## How to Run

1. Clone or download this repository.
2. Install R and configure Jupyter Notebook with an R kernel.
3. Install the R packages required by the notebook.
4. Place the required dataset files in the expected locations.
5. Run the notebook cells in order.

## Evaluation

The classification models are evaluated using the evaluation methods implemented in the notebook. Results depend on the dataset, preprocessing steps, and model settings.

## Limitations

The predictions are intended for analytical and educational purposes. They should not be used as a substitute for professional medical assessment.
